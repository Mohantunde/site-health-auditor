1. Delete the incorrect GitHub repository, or create a new empty public repository
   named: site-health-auditor
2. Extract this ZIP file.
3. Install/open GitHub Desktop.
4. Choose File > Add local repository.
5. Select the extracted folder: site-health-auditor-clean
6. If prompted, choose "create a repository here".
7. Commit all files with:
   Initial release of Site Health Auditor
8. Click Publish repository.
9. Make sure "Keep this code private" is NOT selected.
